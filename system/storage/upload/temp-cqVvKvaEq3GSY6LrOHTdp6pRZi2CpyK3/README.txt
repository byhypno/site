EGESER TEKLİF TALEPLERİ MENÜ V1.0.1
====================================

Amaç:
- Çalışan Teklif Talepleri ekranını admin sol menüye doğrudan ekler.
- Satışlar alt menüsüne bağımlı değildir.
- Sol menüde ayrı bir "Teklif Talepleri" başlığı görünür.

Kurulum:
1. OpenCart Admin > Eklentiler > Eklenti Yükle
2. egeser_teklif_talepleri_menu_v1_0_1.ocmod.zip dosyasını yükleyin.
3. Eklentiler > Modifikasyonlar > Yenile.
4. Admin sayfasında Ctrl+F5.
5. Sol menüde "Teklif Talepleri" görünmelidir.

Not:
- Egeser Teklif Yönetimi V1.0 modülü kurulu kalmalıdır.
- Bu paket yalnızca admin menü bağlantısını ekler.
- Teklif verilerine veya form akışına dokunmaz.
